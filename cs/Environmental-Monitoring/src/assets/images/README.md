# Application Visual Assets (`src/assets/`)

This directory contains lightweight static assets used by the Presentation Tier:

- `icons/` — Clean vector icons (`thermometer.svg`, `humidity.svg`, `status-shield.svg`, `sensor-node.svg`) rendered inside KPI metric cards.
- `images/` — `system-overview-banner.svg` and future team-captured interface or confirmed hardware photographs.
- `media/` — `sample-simulated-readings.json`, an explicitly labelled synthetic sample dataset for offline verification and QA testing.

> **Important:** Do not store large uncompressed video/image binaries or fabricated sensor photographs in this directory.
